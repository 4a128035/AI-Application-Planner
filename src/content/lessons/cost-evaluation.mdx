> 老闆問：「導入這套 AI 要花多少錢？多久能回本？」這一課教你用三個工具回答：**TCO**（到底要花多少）、**Token 成本**（用多少付多少）、**ROI**（值不值得）。

## TCO：別只看 API 帳單

**總體擁有成本**（Total Cost of Ownership, TCO）是「**擁有並使用這套系統的全部成本**」：

| 類型 | 例子 |
|---|---|
| **直接成本** | API／Token 費用、雲端運算與儲存、GPU 訓練、基礎設施、維護人力 |
| **間接／隱性成本** | 系統整合、員工訓練、資安與法規遵循、流程調整、持續監控 |

<Callout type="trap" title="效益不是成本">
  「導入後省下的燃油費」是<strong>效益</strong>，不是成本。它應該放在 ROI 的收益那一邊，不能算進 TCO。
</Callout>

## Token 成本怎麼算

第 1 課說過，API 通常依 **Token 數**收費。**Token Economics** 關心的是**使用（推論）時**的 Token 用量與費用：

<Callout type="key" title="Token 成本公式">
  每月 Token 數 ＝ 每月次數 × 每次的 Token 數（輸入＋輸出）<br />
  每月費用 ＝ 每月 Token 數 ÷ 1,000 × 每 1,000 Token 的單價
</Callout>

如果題目給的是「字數」，要先換算：**Token 數 ＝ 字數 × 每字的 Token 數**。

訓練模型時用掉的 GPU 記憶體成本，屬於另一類成本，**不在** Token Economics 的範圍內。

## ROI 與回收期

**投資報酬率**（Return on Investment, ROI）看的是「值不值得」：

- **每月節省** ＝ 原本的成本 − AI 的每月成本
- **回收期** ＝ 一次性投入 ÷ 每月節省

<Callout type="key" title="完整的 ROI 評估">
  只看「每年省多少」不夠。還要納入<strong>無形效益</strong>（客戶滿意度、品牌形象、員工時間）和<strong>隱性成本</strong>（維護、訓練、合規）。試試看上面計算機的「其他每月成本」：漏算這一項，回收期就會被嚴重低估。
</Callout>

## 雲端 API 還是私有部署？

| | 雲端 API | 私有部署（自建、地端） |
|---|---|---|
| **起步** | 快，按用量付費 | 慢，要先投入硬體與人力 |
| **資料** | 要傳給外部服務 | **留在公司**，自主控管 |
| **適合** | 一般資料、想快速驗證 | 敏感資料、法規要求高（金融、醫療、政府） |
| **代價** | 用量大時費用高、依賴供應商 | 硬體、維運、資安都要自己負責 |

當「**資料安全與法規遵循優先於速度和成本**」時，答案通常是**私有化部署**（例如自行部署開源模型），並同時建立**存取控管與稽核機制**。

## 省錢的方法

| 方法 | 做法 |
|---|---|
| **模型路由**（Model Routing） | 先判斷問題難度：簡單的交給便宜模型，困難的才交給強大模型 |
| **知識蒸餾、量化** | 用更小、更快的模型（第 7 課） |
| **控制思考預算** | 推理型模型依任務複雜度設定思考上限（第 3 課） |
| **縮短提示** | 固定的大量範例改用微調，減少每次送出的 Token（第 7 課） |

<Callout type="trap" title="模型路由 ≠ 負載平衡">
  <strong>負載平衡</strong>看的是「伺服器忙不忙」，把請求平均分給多台伺服器；<strong>模型路由</strong>看的是「問題難不難」，把請求分給適合的模型。
</Callout>

## 常見誤區

<Misconception claim="TCO 就是 API 帳單上的金額">
  <strong>不對。</strong>還有基礎設施、人力、整合、訓練、資安合規等成本。
</Misconception>

<Misconception claim="私有部署一定比較便宜">
  <strong>不一定。</strong>私有部署的好處是資料自主與合規，但硬體、維運與人力成本都要自己承擔。
</Misconception>

<Misconception claim="回收期短，就代表一定值得投資">
  <strong>不一定。</strong>還要看計算時有沒有漏算隱性成本，以及風險與無形效益。
</Misconception>
