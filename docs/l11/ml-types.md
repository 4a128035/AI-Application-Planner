# 機器學習的四種學法

<span class="badge">L11302 常見的機器學習模型</span>

> **先講結論：** 看到情境題，先問一句——**「資料有沒有標好答案？」**，八成的題目就解決了。

## 從學開車說起

想像你要學開車，有四種完全不同的學法：

| 學法 | 學開車的比喻 | 機器學習 |
|---|---|---|
| 🧑‍🏫 教練坐旁邊，每一步都告訴你對錯 | 「這裡要打方向燈」「這裡要減速」 | **監督式學習**：每筆資料都有正確答案（標籤） |
| 👀 沒人教，你在路口觀察一整天車流 | 你自己發現「計程車常停路邊」「機車都擠在前面」 | **非監督式學習**：沒有答案，自己找出資料裡的規律、分群 |
| 🧑‍🏫👀 教練只教了前三堂課，之後你自己上路觀察 | 用教練教的基礎去理解更多路況 | **半監督式學習**：少量有標籤 + 大量沒標籤 |
| 🚗💥 在模擬器裡自己開，撞到扣分、準時到加分 | 沒人告訴你怎麼開，但你知道結果好不好 | **強化式學習**：在環境中試錯，依獎勵調整策略 |

## 一張判斷流程，搞定情境題

```
這個任務的資料有「正確答案（標籤）」嗎？
│
├─ 全部都有 ─────────────→ 監督式學習
│                            ├─ 答案是類別（貓/狗、詐欺/正常）→ 分類
│                            └─ 答案是數字（房價、銷量）     → 迴歸
│
├─ 只有一部分有 ──────────→ 半監督式學習
│
├─ 完全沒有 ─────────────→ 非監督式學習（分群、降維、異常偵測）
│
└─ 不是「資料」，而是「行動 → 獎懲」的試錯 → 強化式學習
```

::: tip 抓關鍵字
- **「已標註」「歷史上已確認的結果」** → 監督式
- **「沒有預先定義類型」「自動分成幾群」** → 非監督式（分群）
- **「部分已標註、其餘未標註」「降低標註成本」** → 半監督式
- **「獎勵」「懲罰」「試錯」「累積報酬」「代理人與環境互動」** → 強化式
:::

## 第五種：自監督式學習

近年考題開始出現 **自監督式學習（Self-supervised Learning）**。它的訓練方式長得像監督式（有答案可對照），但答案是**從資料本身產生的**，不用人工標註。

最有名的例子就是大型語言模型：把一句話的下一個字遮起來，讓模型猜。正確答案就在原文裡，所以可以拿網路上海量的文字來訓練。

::: warning 考試陷阱
「自監督式學習和監督式學習一樣，需要人工逐筆標註」——**錯**。自監督式學習的重點就是**降低對人工標註的依賴**。
:::

## 常見誤區

::: details ❓ 「非監督式學習搭配一點標註資料，就變成監督式學習了」對嗎？
**不對。** 少量標註 + 大量未標註，那叫**半監督式學習**，不是監督式。
:::

::: details ❓ 「監督式學習完全不能做異常偵測」對嗎？
**不對。** 如果有標好的「異常／正常」歷史資料（例如已確認的詐欺交易），監督式分類就能做異常偵測。只是異常樣本通常很少，所以實務上也常用非監督式方法（例如只學「正常長什麼樣子」）。
:::

::: details ❓ 「強化式學習就是會越用越聰明的 AI」對嗎？
**太籠統。** 強化式學習的關鍵是**行動 + 環境回饋（獎懲）+ 最大化累積獎勵**。單純「用新資料重新訓練」不算強化式學習。
:::
