# 關於本站

這是一個三人讀書會準備 iPAS AI 應用規劃師（初級）的學習網站，也是一個**用 AI 協作開發網站**的實作專案：網站的架構、程式與教材都是和 AI 程式助理（Claude Code）一起完成的。

## 系統架構

```
 公開（任何人都能看）                 私人（只有讀書會成員）
┌──────────────────────────┐      ┌──────────────────────────────┐
│ GitHub Pages             │      │ Google Apps Script（後端）    │
│ ・教學單元、圖解、影片      │      │ ・驗證 Google 登入 + 白名單    │
│ ・示範小測驗（瀏覽器批改）  │ ───▶ │ ・出題時不送答案               │
│ ・模擬考介面               │ ◀─── │ ・交卷後由伺服器批改、記錄      │
└──────────────────────────┘      └──────────────┬───────────────┘
                                                 │
                                   ┌─────────────▼───────────────┐
                                   │ Google 試算表（不公開）       │
                                   │ 題庫｜白名單｜作答紀錄        │
                                   └─────────────────────────────┘
```

設計重點：

- **題庫不進公開 repo**：GitHub 上的東西任何人都看得到，所以模擬考題目只存在私人試算表，透過後端取得。
- **伺服器端批改**：出題時只送題目和選項，交卷後才回傳答案與解析，就算打開開發者工具也看不到答案。
- **教材分兩層**：核心概念寫一次就穩定；AI 時事每月更新，因為考題會持續加入新技術。

## 技術

- [VitePress](https://vitepress.dev/)：用 Markdown 寫教材，搭配 Vue 元件做互動測驗
- GitHub Actions：推送後自動建置並部署到 GitHub Pages
- Google Apps Script ＋ Google 試算表：模擬考後端（建置中）

## 聲明

本站為個人學習用途，非 iPAS 官方網站。教材內容與示範題目為自行撰寫，考試資訊請以 [iPAS 官方網站](https://ipd.nat.gov.tw/ipas/AIAP/) 為準。
