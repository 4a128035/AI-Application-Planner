## 考試快速資訊

| 項目 | 內容 |
|---|---|
| 科目 | 科目一 人工智慧基礎概論、科目二 生成式 AI 應用與規劃 |
| 題型 | 每科 50 題單選、75 分鐘、電腦作答 |
| 及格 | 兩科同時考：平均 70 分且每科不低於 60 分；分開考：每科都要 70 分 |
| 題目風格 | 幾乎都是情境題：「某企業想做 X，下列哪一種做法最適合？」 |

::: tip 這個網站怎麼用
每個單元都是「比喻 → 判斷方法 → 考試陷阱 → 小測驗」。小測驗不只告訴你對錯，**每個選項都有解析**——弄懂錯的選項為什麼錯，比背答案更有用。
:::
